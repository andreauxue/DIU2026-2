# Uso de herramientas de IA

Para el desarrollo de esta tarea se utilizó una herramienta de inteligencia artificial (Chat-GPT) con el objetivo de apoyar en la generación de ideas, resolución de dudas y corrección de errores durante la implementación de la interfaz.

## Prompts utilizados

### Número 1

#### Prompt utilizado:

“Estoy desarrollando un sistema de chat con JavaScript para una materia de Diseño de Interfaces de Usuario. Necesito que el asistente pueda responder de forma básica a preguntas relacionadas con temas como HTML, CSS, JavaScript, etc. Dame ejemplos de frases que podría escribir un usuario y qué respuestas debería dar el asistente, de forma sencilla, clara y generica.”

Pregunta: ¿Qué es HTML?

#### Cambios realizados por mí:

A partir de las frases sugeridas por la IA, realicé una función dentro de mi sistema basado en clases (Mensaje y Chat), asegurando que la respuesta del asistente se generara automáticamente después de que el usuario envía un mensaje relacionado con ese tema.
La versión función quedó así:

function respuestaAutomatica(textoUsuario) {
    const texto = textoUsuario.toLowerCase();

    if (texto.includes("html")) {
        return "HTML es el lenguaje que se usa para estructurar el contenido de una página web.";
    }

    if (texto.includes("css")) {
        return "CSS se utiliza para darle estilo a la página, por ejemplo colores, tamaños, márgenes y distribución.";
    }

    if (texto.includes("javascript")) {
        return "JavaScript permite agregar interactividad a la interfaz, como eventos, validaciones y cambios dinámicos.";
    }

    if (texto.includes("flexbox")) {
        return "Flexbox ayuda a acomodar elementos dentro de un contenedor de forma flexible y ordenada.";
    }

    if (texto.includes("div")) {
        return "Un div es un contenedor genérico, mientras que etiquetas como header, main o footer sí aportan significado semántico.";
    }

    return "Encantado de ayudarte";
}

#### Problemas encontrados:

No se encontraron problemas, utilice las frases para poder desarrollar mi función.

function respuestaAutomatica(textoUsuario) {
    const texto = textoUsuario.toLowerCase();

    if (texto.includes("html")) {
        return "HTML es el lenguaje que se usa para estructurar el contenido de una página web.";
    }

    if (texto.includes("css")) {
        return "CSS se utiliza para darle estilo a la página, por ejemplo colores, tamaños, márgenes y distribución.";
    }

    if (texto.includes("javascript")) {
        return "JavaScript permite agregar interactividad a la interfaz, como eventos, validaciones y cambios dinámicos.";
    }

    if (texto.includes("flexbox")) {
        return "Flexbox ayuda a acomodar elementos dentro de un contenedor de forma flexible y ordenada.";
    }

    if (texto.includes("div")) {
        return "Un div es un contenedor genérico, mientras que etiquetas como header, main o footer sí aportan significado semántico.";
    }

    // Respuesta aleatoria
    const indiceAleatorio = Math.floor(Math.random() * respuestasGenericas.length);
    return respuestasGenericas[indiceAleatorio];
}
