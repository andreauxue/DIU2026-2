1. Prompt:
"When i add a task, the text appears outside the li. why is that?" (Se agregó el source code):

The bug is in the order you append elements. Look at this part of your JS:
jsconst span = document.createElement("span");
span.textContent = taskText;  // ← span is created here but...

...
li.appendChild(span);  
Actually the order is okay... the real culprit is that your input CSS rule is too broad. This:

cssinput {
  margin-top: 2em;
  width: 420px;
  ...
}
targets all <input> elements — which shoves it way out and breaks the li layout, making the span appear to float outside.
Fix it by scoping the CSS rule to only the text input:
css/* Before */
input { ... }

/* After */
input[type="text"] { ... }
That way the style only applies to your task input field, and the checkboxes inside each li are left unstyled.
