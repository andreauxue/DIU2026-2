Uso de IA — Documentación

Para esta tarea primero implementé la estructura básica del sistema usando JavaScript.
Ya tenía un arreglo para guardar mensajes y estaba agregando elementos directamente
al DOM.

Después empecé a adaptar el código para usar clases (Mensaje y Chat) y separar mejor
la lógica del render.


------------------------------------------------

Prompt 1:

"Estoy guardando mensajes en un arreglo pero sigo manipulando el DOM directamente.
¿Cómo puedo hacer un render general que reconstruya todo desde el estado?"

Respuesta:

Se sugirió crear una función render() que limpie el contenedor y recorra
el arreglo de mensajes para generar nuevamente el HTML.

Cambios realizados:

Se dejó de usar appendChild directamente y se centralizó todo en la función render().


------------------------------------------------

Prompt 2:

"Ya tengo una clase Mensaje pero no sé bien qué debería regresar en el render().
¿Debe regresar un string o un elemento?"

Respuesta:

Se recomendó que el método render() regrese un string con el HTML del mensaje.

Cambios realizados:

El método render() ahora devuelve un template string con la estructura del mensaje.


------------------------------------------------

Prompt 3:

"Quiero simular que el asistente responde después de un tiempo y que aparezca
algo como 'escribiendo...'. ¿Cómo lo puedo hacer sencillo?"

Respuesta:

Se sugirió usar setTimeout para agregar primero un mensaje temporal y luego
la respuesta final.

Cambios realizados:

Se agregaron dos setTimeout para simular el comportamiento del asistente.


------------------------------------------------

Problemas encontrados:

Al inicio seguía manipulando el DOM directamente en varias partes, lo cual
no cumplía con el flujo Estado → Render → Interfaz.

Después de reorganizar el código, todo el render se centralizó y el
comportamiento fue más predecible.
