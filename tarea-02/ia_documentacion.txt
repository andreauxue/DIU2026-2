CAMBIOS REALIZADOS:
-------------------
- Se corrigió getElementById('.chat') por querySelector('.chat') ya que .chat es una clase y no un id

- Se corrigió el typo 'summit' por 'submit' en addEventListener, ese error hacia que el botón no funcionara

- Se cambió createElement('li') por createElement('div') para que coincidiera con las clases del CSS existente

- Se eliminó código duplicado que tenía dos addEventListener haciendo lo mismo

- Se adaptaron los nombres de variables al estilo del alumno usando nombres en español como formulario, inputMensaje

- Se corrigió el HTML que tenía dos etiquetas <nav> duplicadas,el botón limpiar y contador se movieron al nav correcto

- Se dejó la respuesta del asistente como mensaje fijo ya que no se implementaron respuestas personalizadas por palabras clave


PROBLEMAS ENCONTRADOS:
----------------------
- El chat no aparecía porque getElementById no acepta punto,
  ese es exclusivo de querySelector para buscar por clase

- El formulario no respondía por el typo 'summit' en lugar de 'submit', un error de escritura que es difícil de ver xd

- Los mensajes no tenían el estilo del CSS porque se usaba la clase 'mensaje-item' que no existía, las clases correctas eran 'mensaje' y 'usuario' que sí estaban definidas

- El HTML tenía dos etiquetas nav lo que causaba que el botón limpiar y el contador no estuvieran en el lugar correcto

- La función limpiarInput() usaba una variable 'input' que no estaba definida, la constante correcta era 'mensaje' xd 

- Al principio render() y el listener hacían lo mismo por separado, se unificó para seguir el flujo estado → render → interfaz
