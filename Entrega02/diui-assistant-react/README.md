## Requisitos previos

Antes de ejecutar el proyecto es necesario tener instalado:

- Node.js
- npm

---

## Instalación

Abrir una terminal dentro de la carpeta del proyecto:

```bash
cd Entrega02/diui-assistant-react
```

Instalar las dependencias:

```bash
npm install
```

---

## Ejecución del proyecto

Para iniciar el servidor, ejecutar:

```bash
npm run dev
```

Después de ejecutar el comando aparecerá una dirección similar a:

```txt
http://localhost:5173/
```

Abrir esa dirección en el navegador para visualizar el chatbot.
